<!-- BUN -->

- Usa el motor de JavaScriptCore (Safari)
- A diferencia de Google Chrome que usa el moto V8 / Node

Tenemos 4 herramientas en 1:

- Gestor de paquetes => bun install
- Runtime (ejecutor) => bun run index.ts
- Bundler (empaquetador) => bun build
- Test runner => bun test

Iniciar un proyecto => bun init
Instalar todo => bun install
Añadir un paquete => bun add nombre_paquete
Añadir a dev => bun add -d nombre_paquete
Quitar => bun remove nombre_paquete
Ejecutar archivo => bun run nombre_archivo
Ejecutar binario => bunx nombre_paquete
