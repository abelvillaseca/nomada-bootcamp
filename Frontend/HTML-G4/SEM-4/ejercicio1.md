Ejercicio: Tablero de tareas con componentes modernos de HTML

Este ejercicio integra cuatro características importantes de HTML moderno:

- <template> para reutilizar estructuras HTML.
- loading="lazy" para optimizar la carga de imágenes.
- Drag and Drop API de HTML para mover elementos.
- <dialog> para mostrar un cuadro de diálogo nativo.

Además, el diseño utiliza un estilo minimalista inspirado en Apple: mucho espacio en blanco,
colores neutros, bordes suaves y sombras ligeras.
