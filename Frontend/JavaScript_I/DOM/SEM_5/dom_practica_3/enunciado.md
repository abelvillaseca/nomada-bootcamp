Panel de reservas de un cine.

- Una lista inicial de películas
- Información de cada película (objetos)
- Un formulario para seleccionar la película y registrar una reserva
- Un arreglo donde se almacenan las reservas
- Cálculo automático del precio
- Contador de reservas
- Búsqueda y filtrado de información
- Eliminación de reservas
- Actualización dinámica del DOM
- Usar todos los métodos vistos en clases anteriores

1. Enunciado
   Una cadena de cines necesita una pequeña aplicación para registrar las reservas de sus clientes.

- La aplicación debe mostrar al menos tres películas disponibles
- Cada película tendra: id, titulo, genero, duracion, precio, disponible
- El usuario debe poder:
  - Seleccionar una película
  - Escribir su nombre
  - Seleccionar la cantidad de entradas
  - Registrar la reserva
  - Visualizar inmediatamente la reserva en pantalla
  - Eliminar una reserva haciendo clic en el botón correspondiente
  - Ver estadísticas generales
- La aplicación deberá calcular:
  - Número total de reservas
  - Número total de entradas vendidas
  - Dinero recaudado
  - Película más reservada
  - Si existe alguna película agotada
  - Si todas las películas siguen disponibles
